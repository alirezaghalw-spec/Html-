# HTML App Studio — Android APK

این پروژه یک اپلیکیشن اندرویدی بومی (Kotlin) است. رابط کاربری و ویرایشگر داخل APK اجرا می‌شوند؛ برای استفاده نیازی به مرورگر یا هاست وب نیست.

## ساخت APK فقط با GitHub
1. تمام فایل‌های این پروژه را در ریشه یک مخزن GitHub جدید آپلود کن.
2. از تب **Actions** وارد workflow با نام **Build Android APK** شو.
3. اگر workflow به‌صورت خودکار اجرا نشده، روی **Run workflow** بزن.
4. پس از پایان موفق، وارد اجرای workflow شو و از بخش **Artifacts** فایل `html-app-studio-apk` را دانلود کن.
5. ZIP مربوط به Artifact را باز کن و `app-debug.apk` را روی گوشی نصب کن. ممکن است اندروید برای نصب از منبع ناشناس اجازه بخواهد.

## امکانات
- رابط فارسی شیشه‌ای
- ویرایش و اجرای HTML داخل خود اپ
- ذخیره چند پروژه در حافظه خصوصی برنامه
- انتخاب، حذف و خروجی گرفتن HTML
- بدون نیاز به سرور یا مرورگر خارجی

## نکته
این نسخه APK آزمایشی (debug) می‌سازد و برای نصب شخصی مناسب است. برای انتشار عمومی در فروشگاه‌ها باید نسخه release امضاشده ساخته شود. اطلاعات پروژه‌ها داخل حافظه خصوصی اپ ذخیره می‌شود؛ با حذف برنامه یا پاک‌کردن داده‌های آن ممکن است از بین برود.
